# Conceitos de logo — rodada 4 (símbolos sem letras)

Gerados com a skill [logo-design](https://github.com/kaankiziltug/logo-design-skill). Preto primeiro; `preview-metal.png`
mostra prata sobre preto e a gravação num cartão de metal.

**Brief:** sóbria e premium, com toque de ofício; lingote + forja; liberdade = independência; maturidade financeira;
só preto + prata/platina; referência: fintechs premium (Apple Card, Amex Centurion, Revolut Metal). Evitar: frio/geométrico
demais e cara de cripto.

**Restrição nova:** o nome pode mudar, então nada de iniciais, letras ou o "2" — só símbolos.

| | Conceito | Ideia |
|---|---|---|
| **A** | Selo do lingote | A marca de pureza da refinadora, com o lingote batido nela: procedência e confiança. |
| **B** (recomendado) | Barra que se paga | A camada de cima do lingote — o rendimento — desliza para pagar; a barra fica inteira. |
| **C** | Fora do molde | A barra pronta sai do molde: valor construído com o tempo, agora independente. |

- `v1/`, `v2/` — rodadas 1–2 (frias/geométricas, cara de cripto). `v3/` — rodada 3 (usava Y2 e o "2" do nome).
- Curvas ainda estão poligonizadas (muitos pontos) — normal para exploração; a versão final é redesenhada com arcos limpos.
- Regerar: `pip install shapely && python3 generate.py .`

## Rodada 5 — 20 símbolos (`rodada-5/`)

Vinte esboços rápidos, sem letras, para o usuário reagir por número: `rodada-5/sheet.png` (visão geral),
`01.svg`…`20.svg` (mestres em preto), `concepts.json` (nome e ideia de cada um). Regerar: `python3 rodada-5/generate.py rodada-5`.
